# Evidence Register — NOPEC SOC 1 2025 Examination

**Engagement:** NOPEC [Electric | Gas]
**Examination Period:** January 1, 2025 – December 31, 2025
**Purpose:** Maintain immutable record of audit evidence received, including
SHA-256 hashes for IPE integrity preservation under AT-C 205.

> **Discipline:** Append-only. Never delete or modify prior entries. If a file
> is superseded, log the new file as a separate entry and cross-reference.

## Hash Verification Procedure (for Reviewer Re-Performance)

To verify a file matches its registered hash:

```bash
# Single file verification
echo "<expected_hash>  /nopec_2025/.../01_population_received/<filename>" | \
    sha256sum -c

# Bulk verification across all received files
find /nopec_2025/electric/01_population_received -type f -exec sha256sum {} \; \
    > /tmp/current_hashes.txt
diff /tmp/current_hashes.txt /nopec_2025/electric/registered_hashes.txt
```
